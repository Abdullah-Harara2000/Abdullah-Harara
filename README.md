# 🐛 لعبة الدودة

لعبة الدودة الكلاسيكية التفاعلية بواجهة عربية كاملة!

## 🎮 تجربة اللعبة

يمكنك تجربة اللعبة مباشرة على: **[اضغط هنا للعب](https://abdullah-harara2000.github.io/Abdullah-Harara/)**

## ✨ المميزات

- 🌟 واجهة عربية كاملة مع دعم RTL
- 📊 نظام نقاط مع حفظ أعلى النقاط
- ⚡ سرعة متزايدة مع التقدم في اللعبة
- 🎨 تصميم عصري بألوان متدرجة جميلة
- 📱 متجاوب مع جميع الشاشات (موبايل، تابلت، كمبيوتر)
- ⏸️ إمكانية الإيقاف المؤقت
- 🍎 رسومات جميلة

## 🎯 كيفية اللعب

1. اضغط على زر **"ابدأ اللعبة"**
2. استخدم أزرار الأسهم (⬆️ ⬇️ ⬅️ ➡️) للتحكم بالدودة
3. اجمع التفاح 🍎 لزيادة النقاط وتكبير الدودة
4. تجنب الاصطدام بالجدران أو بجسم الدودة نفسها

## 🎮 التحكم

- **أزرار الأسهم**: التحريك في الاتجاهات الأربعة
- **زر المسافة**: إيقاف مؤقت/استئناف
- **زر "إيقاف مؤقت"**: لإيقاف اللعبة مؤقتاً

## 🚀 تشغيل اللعبة محلياً

### الطريقة الأولى: فتح الملف مباشرة
```bash
# افتح ملف index.html في المتصفح مباشرة
open index.html  # في Mac
start index.html # في Windows
xdg-open index.html # في Linux
```

### الطريقة الثانية: استخدام خادم محلي
```bash
# باستخدام Python 3
python3 -m http.server 8000

# ثم افتح المتصفح على
# http://localhost:8000
```

### الطريقة الثالثة: استخدام Node.js
```bash
# تثبيت http-server
npm install -g http-server

# تشغيل الخادم
http-server

# ثم افتح المتصفح على العنوان الذي يظهر
```
